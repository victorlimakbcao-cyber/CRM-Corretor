Crie uma aplicação web full-stack chamada provisoriamente CRM Corretor, voltada para corretores de imóveis no Brasil.

O sistema deve ser funcional, não apenas um protótipo visual. Quero frontend, backend, banco de dados, autenticação, CRUDs, filtros, relacionamentos e dashboards funcionando.

OBJETIVO PRINCIPAL

O CRM deve ajudar o corretor a:

não perder leads;
organizar clientes;
cadastrar imóveis;
controlar captação;
acompanhar negociações;
agendar visitas;
registrar propostas;
controlar follow-ups;
acompanhar vendas;
calcular comissões;
encontrar imóveis compatíveis com cada cliente.

Inicialmente será usado por um único corretor, mas a arquitetura deve estar preparada para múltiplos corretores e imobiliárias futuramente.

STACK

Utilize preferencialmente:

TypeScript
React ou Next.js
Tailwind CSS
shadcn/ui ou componentes equivalentes
PostgreSQL
Drizzle ORM ou Prisma
API backend organizada
autenticação segura
arquitetura responsiva

Caso alguma tecnologia não seja adequada ao ambiente atual do Replit, utilize a alternativa mais estável disponível, mantendo a mesma arquitetura.

Não crie apenas dados estáticos no frontend.

Todos os principais registros devem ser persistidos no banco.
